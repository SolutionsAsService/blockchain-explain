The bridge between stacks

Layer 0: chains that talk

One chain cannot read another's state. Layer 0, as this site uses the term, is what connects them: here, IBC, the Inter-Blockchain Communication protocol.

What IBC does

Each chain runs a light client of the other: a small program that follows the other chain's block headers and checks its validators' signatures. A relayer, an ordinary program anyone can run, carries packets and their proofs between the two. The receiving chain checks each proof against its light client before acting, so the relayer never needs to be trusted.

Sovereign chains

Connected chains do not merge. Each keeps its own validators, rules and upgrades, and they agree only on how to pass messages. That is the difference between this and a single bigger chain.

“Layer 0” has no single standard meaning: projects use it for different things. On this site it means the connection between chains, drawn as the bridge on the home page.
