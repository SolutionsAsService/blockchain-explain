About this site

A plain guide to how blockchains work, for anyone. Version 1 of this site explained one project, Autheo, with numbers typed by hand. Version 2.0 is a general guide, and it computes every value it shows.

01How the numbers are made

_src/build.py computes every hash and count on the site with Python and writes it into the pages. In your browser, js/demos.js recomputes the same values with Web Crypto, so when you change an input, the result is real. On load, each page checks its own defaults against the values the build wrote.

02The logo

Version 1 was three bars in a frame, the lowest one green. Version 2.0 turns them into three slabs of the stack, keeps the green base, and runs a transaction's path down through them. Both are in the repository, in brand/.

03Sources

Each page links the documentation it rests on: the Bitcoin paper, ethereum.org, the CometBFT, IBC and Solana documentation, L2BEAT and NIST. What any one project says about itself is given only as that, as in the Autheo case study.
