The bedrock, under every level

The basics

A blockchain is a list of blocks, each holding the fingerprint of the one before, kept by many computers at once. Three ideas make it work, and each one runs in your browser.

In one lineA blockchain is a shared list where every entry carries the fingerprint of the one before, so changing the past shows.

01A hash is a fingerprint

SHA-256 turns any text into 64 hexadecimal digits (the digits 0–9 and the letters a–f). The same input always gives the same hash, and the smallest change gives a completely different one. It is collision-resistant: nobody knows how to find two inputs with the same hash.

02Blocks chained by their hashes

Each block's hash covers its number, its data and the previous block's hash: SHA-256(number | previous | data). Change any old block and its hash changes, so the next block's “previous” no longer matches.

Try it · break the chain

Edit a block's data. The link after it snaps. “Re-link” repairs one block at a time, and each repair moves the break down the chain.

03Merkle trees: one hash for many

A block's header does not list every transaction. It holds one Merkle root: hash each transaction, hash the hashes in pairs, and repeat until one is left. A short path of hashes then proves that one transaction is in the block, without the whole list.
