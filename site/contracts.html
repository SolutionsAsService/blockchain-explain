Smart contracts

Some chains store programs as well as payments. Anyone can call them, and every node runs the call and must reach the same result.

Programs everyone runs

A smart contract is a program saved on the chain at its own address. Calling it is a transaction: every node runs the code with the same inputs, so they all reach the same new state. Nobody can change a contract's code once it is deployed, unless the code itself allows it.

Bitcoin allows only small, fixed scripts. Ethereum made general programs the point: its Ethereum Virtual Machine (EVM) runs contracts usually written in Solidity, and many other chains run the same EVM so those contracts work there too.

Gas

Since every node runs every call, each step of computation costs a fee, called gas on Ethereum. The fee pays the network and stops a program from running forever.

What people build

Tokens (a contract that keeps a list of balances), exchanges that trade them without a company in the middle, lending, collectibles (NFTs), and votes for groups that hold funds together. Each is a contract, and each is only as safe as its code: see Risks.
