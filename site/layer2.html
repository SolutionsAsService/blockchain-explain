Layer 2: scaling on top

If every node must run every transaction, a chain must choose between speed and letting ordinary computers check it. Layer 2 systems do most of the work elsewhere and use the chain as the judge.

In one lineDo the work off the chain, post the results to it, and let the chain judge.

01Rollups

A rollup runs transactions off the main chain, then posts them in compressed batches back to it. The main chain (layer 1) publishes the data for everyone, so anyone who downloads it can rebuild the rollup's state and check it.

  • Optimistic rollups assume each batch is correct, and allow a challenge period in which anyone can prove a batch wrong.
  • Zero-knowledge rollups post a cryptographic proof with each batch that it was computed correctly.

02Payment channels

Two people lock funds on the chain, then pay each other many times off it by signing updated balances, and settle the final balance on the chain. Bitcoin's Lightning Network links channels into a network.

03What it costs

Layer 2s inherit the main chain's security only as far as their design allows: who can post batches, how a user leaves if the operator stops, and how long withdrawals take all differ. L2BEAT tracks these differences for each one.
