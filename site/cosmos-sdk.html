The Cosmos SDK

  1. EVMExecution
  2. Cosmos SDKApplication framework
  3. CometBFTConsensus

Consensus orders transactions but does not know what they mean. The Cosmos SDK is a framework for writing that meaning: the chain's own application.

ABCI: the line between the two

CometBFT hands each block to the application through an interface called ABCI (the Application Blockchain Interface). The application checks each transaction, applies it, and reports back. Consensus never needs to understand balances or contracts. It only needs the order.

That split is why the Cosmos SDK can build very different chains on the same consensus engine.

Modules

A Cosmos SDK chain is assembled from modules, each one owning a part of the state: bank for balances, staking for validators and their stake, gov for on-chain votes, and ibc for talking to other chains (see Layer 0). A chain built this way is called an application-specific blockchain: it exists to run one application well.
